```sh
git vault list [options]
```

List the original repository-relative paths saved in the selected profile.

| Option | Purpose |
| --- | --- |
| `-b`, `--branch NAME` | Local branch to use (default: `vault`). |
| `-p`, `--profile NAME` | Profile (default: `default`). |
| `-h`, `--help` | Show help. |

---
title: list
description: プロファイルに保存されているパスを一覧表示する。
section: reference
order: 10
---

```sh
git vault list [options]
```

選択したプロファイルに保存されている、元のリポジトリ相対パスを一覧表示します。

| オプション | 説明 |
| --- | --- |
| `-b`, `--branch NAME` | 使用するローカルブランチ（デフォルト: `vault`）。 |
| `-p`, `--profile NAME` | プロファイル（デフォルト: `default`）。 |
| `-h`, `--help` | ヘルプを表示する。 |

`git-vault`は、暗号化ファイルをアプリケーションのコードとは別のorphanブランチ（履歴を共有しないGitブランチ）に保存します。

APIキーやパスワードなどのシークレット管理では、リスクと運用コストのバランスが重要です。小規模なプロジェクトでは、シークレットを含むファイルを暗号化してリポジトリにコミットする方法が、実用的な選択肢になります。

git-vaultは、`.env`などのファイルを同じリポジトリ内の専用ブランチに暗号化して保持します。アプリケーションのブランチに暗号化ファイルや設定を追加せず、使い慣れたGitのワークフローでコードとシークレットを一緒に管理できます。

<h2 id="trade-offs">トレードオフ</h2>

この方法には制約があります。暗号化したシークレットはリポジトリのクローン時にコピーされ、コミット履歴にも残るため、完全な削除は困難です。git-vaultは、そのトレードオフを受け入れても、コードとシークレットをひとつのリポジトリで扱う利便性を優先したいプロジェクト向けに作られています。

<h2 id="requirements">要件</h2>

- Python 3.11以降
- Git
- [age](https://github.com/FiloSottile/age)（鍵の生成には`age-keygen`が便利です）
- macOSまたはLinux
